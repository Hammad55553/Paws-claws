# Paws & Claws Digital Haven

Build a new production-quality, modern and highly animated responsive website for **Paws & Claws Animal Hospital** in Faisalabad, Pakistan. This is a veterinary hospital/clinic website for pets (dogs and cats), not an e-commerce site. Use the Paws & Claws logo provided by the user as the official brand identity and favicon/icon; preserve its exact identity and colors. The business-card references contain the doctors, services, contact details, and address.

CONTACT: Paws & Claws Animal Hospital | Phone 0325-6036198 | Email pawsandclawsah199@gmail.com | Address: West Canal Road, Near Canal Garden, Faisalabad.
DOCTORS: Dr. Haris Rizwan — DVM (LHR), RVMP (ISB); Dr. Abdur Rafay — DVM (LHR), RVMP (ISB).
SERVICES (exactly these 12): Surgery, Grooming, Pet Accessories, Boarding, Vaccination, Ultrasound, Pet Food, Laboratory, Deworming, Day Care, Home Visit, Microchipping.

DESIGN: premium friendly veterinary hospital aesthetic, green + blue palette from the logo, clean white space, dark navy text. Make it alive and pet-focused with tasteful animated dogs/cats, floating paw particles, smooth entrance/reveal animations, hover interactions, soft organic blobs/waves, animated counters/cards, and smooth scrolling. Keep animations professional, smooth and performant. Hero must immediately communicate trusted pet care, with animated pet imagery/illustrations and prominent Call Now + Book an Appointment CTAs. Sticky responsive navbar with logo and Home, About, Services, Doctors, Contact. Include polished hero, trust/benefits, 12-service interactive grid, doctors, about/why choose us, appointment CTA, contact/location, footer. Doctors must use only the supplied names/credentials; do not invent qualifications, awards, stats, certifications, hours, prices, or medical claims. Contact details must be actionable. Include a map/location area using the address without inventing coordinates. Add appointment/contact form UI for now; no admin panel yet, but structure the public site so an admin panel can be added later. Add mobile floating call/appointment action. SEO-friendly, semantic, accessible, responsive, performant. Do not add fake reviews, fake patient counts, fake emergency/24-7 claims, or unsupported medical promises. Make it look like a real professional veterinary hospital website ready for a client presentation.
